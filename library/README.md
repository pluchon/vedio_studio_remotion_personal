# 公共资料库

跨期复用的图片、文章、音乐放这里，只收这三类（文章目前没收）（念白、乐器采样库、某一期专用的原始素材不放这里）。

```
library/
├─ README.md     # 本文件
├─ INDEX.md      # 目录：每个文件一行，写清来源、许可、一句话说明（入库）
├─ music/        # 配乐：现成的、从别的视频里提出来的（Demucs）、自己合成的
├─ images/       # 图片、贴图、插画
└─ articles/     # 文章、文案、资料
```

## 规矩

- **只收真实来源的内容，不收 AI 生成的**（图片、文章、音乐都一样），保证这个库是干净的。你自己写的、别人写的文章也先不收。

- **随用随取**：新一期要用时，把需要的文件**复制一份**放进这一期自己的文件夹（`refer/<期名>/` 讨论阶段，或 `public/<名字>/` 渲染要读的），不要让视频直接读 `library/`。
- **文件本体不入库**：仓库是公开的，`library/` 里除 `README.md` 和 `INDEX.md` 外都被 `.gitignore` 忽略，只留在本机。换了机器，按 `INDEX.md` 里记的来源重新找。
- **进了库就登记**：往里放东西时，在 `INDEX.md` 加一行；没有登记的文件，我不会当成现成素材用。
- 某一期用到的文件如果许可允许公开（CC0、公有领域、自己合成的），复制到那一期的 `public/` 后可以入库；有版权的只留本机，并写进根目录 README 的「不入库的素材」表。

## 怎么放

文件名写清楚内容，不用编号：`music/宇宙杂谈-背景音乐.wav`、`images/哈勃深空场.jpg`。
提取配乐用 `python tools/common/separate.py <音频> library/music`。

# 《宇宙漫游》（成片 ID `Wander`）

> 一个文明从海里的一团分子，到点亮半条旋臂，再在「意识之海」里安静地熄灭；星海始终在闪耀。没有念白，文字上屏，时间轴跟着作者自己的曲子走。全片是 Skia 着色器画的插画动画，约 70 个镜头，首尾是同一张真实的哈勃超深场
> 第 15 期 · 约 4 分 56 秒 · 渲染：`npm run render -- Wander`（带 `--gl=angle --color-space=bt709 --concurrency=3`）

## 文件

- `Compositions.tsx`、`Film.tsx`：成片 `Wander`；`Film` 里的 `CUTS` 表按配乐的秒数排出每个镜头（组件、开始、结束、淡入、淡出），后一个叠在前一个上淡入
- `theme.ts`：帧率、总长、配乐里的几个节点（`BEAT`）、字体
- `time.tsx`：`useT()` 拿整片的秒数（放进 `Scene` 的 Sequence 里也一样），缓动和关键帧
- `script.ts`：上屏的全部文字和时间——正文、资料小字（左上角，真实研究，数字和出处不改）、图片标注、片尾
- `Text.tsx`：片名、正文（一个字一个字浮出来）、资料小字、图片标注、片尾
- `art/`：画面
  - `sk.tsx`：Skia 的公用件——编译着色器、SkSL 噪声库、泛光（亮部模糊后叠回去）、胶片颗粒和暗角、`Shot`（一个镜头的画布）
  - `space.tsx`：会流动的星云、几层会闪的星、旋涡星系（星点会旋进来聚成形）、椭圆星系、光子
  - `bodies.tsx`：恒星（米粒组织、日冕）、行星（着色器画的球：海、陆、云、海面高光、夜面城市灯、大气）
  - `world.tsx`：水下（焦散、光柱）、黄昏的天和海（云、太阳倒影）、银河、有光泽的分子、细胞膜、气泡、浮游的微粒、山和岩石的剪影
  - `critter.tsx`：那个生灵——沿脊柱按粗细生成平滑轮廓，上亮下暗、边缘光、背上一排发光的斑点，能游、走、抬头、坐、说话、变成剪影
  - `props.tsx`：火焰着色器、火星、十二个发光的符号（它们的「字」）、洞壁岩石、烟、城市天际线（窗灯能亮能灭）、星图网络（按「离已亮的最近」排出点灯顺序，能点亮也能从边疆往回熄）
  - 各段的镜头：`Prologue`（序）、`Dawn`（一 · 微光）、`Hearth`（二 · 火）、`Rise`（三 · 宏伟）、`Ages`（四 · 时间的尘埃）、`Expanse`（五 · 疆域）、`Ascend`（六 · 跃迁）、`Coda`（七 · 熄灭和尾 · 星海）

## 做法

- 没有念白，时间轴就是配乐。频谱分析找出的节点（`BEAT`）：0:31 深低音和高处的空气感同时进来，是「有东西动了」，镜头冲进星系；2:05 高频抽空，是「可宇宙并不急着回答」，画面跟着褪色落灰；2:35 回来，是「可它们没有停步」，舰队出发；3:38 最高处是光之曼陀罗；4:07.6 静下来，是最后一扇窗熄灭。
- 镜头 4–6 秒一换，每个镜头有远中近景、飘浮的粒子和一个缓慢的运镜；好几处做了呼应：生灵背上的光点→火→城市灯火；海里的分子链→蓝图里的双螺旋；洞壁的符号→说话的符号→意识之海里升起的符号；开场的星系→天文台目镜→尾声；开场的光子→尾声里它还在路上。
- 真实照片只在首尾：开头三秒的超深场就地「画」成扁平的宇宙（星系画在照片里同样的位置），结尾再收回去，落回和第一帧一模一样的构图。
- 「一颗，十颗，一千颗」：点灯数在对数刻度上分段线性（`Expanse.tsx` 的 `countAt`），三个词出现时正好是 1、10、1000。
- **Skia 画布里拿不到外面的 React context**：`useT()` 必须在镜头组件（画布外）里调用，再把 t 当参数传进画布里的组件；画布里自己调 `useT()` 拿到的是本镜头内的秒数，东西会「不出现」。
- 泛光会把橙色的生灵也照成一团白，生灵放在 `Bloom` 外面画，只让火、星、光点进泛光。

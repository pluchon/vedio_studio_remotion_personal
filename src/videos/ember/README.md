# 《宇宙漫游》重制版（成片 ID `Ember`）

> 第十五期《宇宙漫游》的重制：同一份稿子、同一首曲子，换成电影的拍法。一张 WebGL2 画布逐帧算出全部画面——体积渲染的旋涡星系、带大气散射和城市灯火的行星、算出来的日落和银河、篝火、洞壁、深海里会复制自己的分子、意识之海——60fps、2.4:1 画幅，正文写在下边的黑边里。首尾是同一张真实的哈勃超深场
> 第 17 期 · 约 4 分 56 秒 · 渲染：`npm run render -- Ember`（带 `--gl=angle --color-space=bt709 --concurrency=2 --timeout=300000`，核显约 40 分钟）

## 文件

- `Compositions.tsx`、`Film.tsx`：成片 `Ember`（1920×1080，60fps）；`Film` 里是画布、文字和两条音轨（配乐、音效）
- `theme.ts`：帧率、画幅（2.4:1，上下各 140 像素黑边）、配乐里的节点（`BEAT`）、字体
- `script.ts`：上屏的全部文字和时间（和第十五期同一份稿子）；`Text.tsx`：片名、正文（下黑边里一个字一个字浮出来）、资料小字（上黑边左边）、图片标注（上黑边右边）、片尾
- `Screen.tsx`：整片唯一的 WebGL 画布，开头把所有着色器并行编好，然后每帧按镜头表画
- `gl/engine.ts`：引擎——每个镜头一个片元着色器，画进半精度 HDR 缓冲；镜头之间按透明度叠化；泛光（13 采样缩小 + 帐篷放大）、ACES、调色、暗角、色差、颗粒；`raw` 让真实照片按原样显示
- `gl/lib.ts`：共用 GLSL——贴图版三维值噪声（一次采样）、分形噪声、相机、黑体颜色、按像素尺度放置的星空；`gl/post.ts`：后期的几个着色器
- `shot.ts`：镜头表的类型、关键帧（`keys`/`keys3`）、和着色器一致的三维投影（`project`，给 Canvas 叠加用）、按时间算图层和后期参数
- `draw.ts`：Canvas 2D 的发光线条和光点
- `presets.ts`：类地行星的配色和大气、地面看天时太阳和银河的摆法
- `scenes/`：场景着色器
  - `deep.ts` 超深场原图 + 三维的程序星系场；`galaxy.ts` 体积渲染的旋涡星系（解卷坐标里的噪声、尘埃带、电离氢区、按像素分级的盘面恒星）、第二个星系、光子、冲进盘里时流过的恒星
  - `planet.ts` 行星（扭曲的分形地形、云和云影、海面高光、单次散射大气、夜里的气辉；城市灯火分三层：底光、城市的芯和晕、按像素分级的小镇；按「到达时间」铺开、按「熄灭顺序」暗下去；发射的光迹、轨道光环）
  - `sky.ts` 地面看的天（地球尺度的单次散射 + 暮色补光、银河、气辉）；`land.ts` 海岸 / 旷野（高度场步进 + 二分细化、海浪和白沫、篝火的火焰和火星、围坐的身影、聚落灯火、射电望远镜、月光）；`under.ts` 水下往上看（斯涅尔窗、光柱、焦散）
  - `cells.ts` 会复制自己的分子（光线步进的螺旋骨架和横档）/ 两点光合一；`fire.ts` 火的特写 / 最后一点余烬；`cave.ts` 洞壁（火光、影子、赭石符号、冷光束和尘埃）
  - `ship.ts` 飞船；`star.ts` 恒星和戴森云的轨道带；`board.ts` 画板（给 Canvas 画的示意图、星图）；`sea.ts` 液面 / 意识之海；`flow.ts` 光的丝（两个世界、缠绕、曼陀罗、光路）
- `shots/`：镜头表，一段一个文件（`prologue` 序、`dawn` 一、`hearth` 二、`rise` 三、`ages` 四、`expanse` 五、`ascend` 六、`coda` 七和尾）；`index.ts` 把它们接起来，并让前一个镜头等后一个完全淡入才撤

## 做法

- 时间轴就是配乐（`BEAT`）：0:31 冲进星系，2:05 抽空时画面褪色落灰，2:35 船队出发，3:36–3:52 最高处是光之曼陀罗，4:07.6 最后一点火苗熄灭。
- 呼应：开场的星系→尾声退回同一个星系、光子还在路上；海里的分子一分为二→两点光合一；篝火→最后一点余烬；洞壁的符号→落灰→散成光点；第一片海→意识之海；首尾同一帧超深场。
- 着色器在 ANGLE（D3D11）上编得很慢（大的十几秒），所以 `Screen` 在开头用 `KHR_parallel_shader_compile` 把全部着色器一起编好再开始画；每个标签页约 45 秒，渲染时要 `--timeout=300000`。
- 同一个着色器被几个镜头共用时，镜头没给的 uniform 会被清零（`engine.ts`），不会沿用上一个镜头的值。
- 自查：`node tools/ember/frames.mjs <输出目录> 12.5 40 61.2 ... --sheet` 打包一次、按秒数渲多张静帧，再拼一张缩略图总览。

## 已知局限

- 我听不到声音：音效的响度是对着配乐逐秒比的。第一版环境声比配乐低 13–20 dB，作者看完说偏大、偏多，于是整体减半（-6 dB），并去掉了虫鸣、船队后面几声呼啸、异星家园切换的呼啸、笔划声、意识之海的高频闪光、熄灯时的轻响，分子横档的轻响减半。
- 画面全是程序算的示意，不是任何真实天体的复原；「意识之海」是原创设定，画面上开头标了「以下是一种想象」。

# 《一场雨》（成片 ID `Rain`）

> 画面由配乐波形驱动，噪声、路径动画、弹簧，首尾循环
> 第 5 期 · 30 秒 · 渲染：`npm run render -- Rain`

## 文件

- `Compositions.tsx`：成片 `Rain`
- `score.ts`：在公用的谱（`src/shared/audioScore.ts`）之上，读出这首曲子雨下大、换气、重新起音三个时刻
- `plan.ts`：由这三个时刻推出水滴和镜头的走位
- `theme.ts`：配色与整张竖长画面的布景尺寸
- `parts/`：窗外失焦的街灯与雨丝、像透镜一样映着窗外的水珠
- `scenes/`：Glass 窗玻璃到窗台，Yard 屋檐、灯笼、枝叶和水洼

## 素材与不入库的东西

- 配乐 `public/rain/audio/su.mp3` 不入库。画面是从这首曲子的波形里算出来的，换一首曲子雨也会跟着变。画面全部由代码画，没有图片。

## 要点

- 一个镜头跟着一滴雨，从窗玻璃落进水洼，首尾相接可以循环。
